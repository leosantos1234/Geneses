# Catálogo de eventos

| Stage | Eventos implementados |
|---|---|
| CANDIDATE | `DECISION_CREATED` |
| MARKET_CONTEXT | `MARKET_CONTEXT_CAPTURED` |
| STRATEGY | `STRATEGY_EVALUATED`, `STRATEGY_SELECTED` |
| COMMANDER | `COMMANDER_EVALUATED`, `COMMANDER_ALLOWED`, `COMMANDER_BLOCKED` |
| RISK | `RISK_ALLOWED`, `RISK_BLOCKED` |
| EXECUTION_GATE | `EXECUTION_GATE_EVALUATED`, `EXECUTION_BLOCKED` |
| ORDER | `ORDER_INTENT_CREATED`, `ORDER_ACCEPTED`, `ORDER_REJECTED` |
| POSITION/OUTCOME | `POSITION_OPENED`, `DECISION_FINALIZED` |

Eventos carregam status, componente, motivo e payload limitado. Nenhum evento expõe chave, segredo, senha, token ou DSN.
